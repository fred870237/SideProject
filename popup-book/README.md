# 機關書 📖

給小朋友點點看的機關書網頁（純 HTML/CSS/JS，不需要安裝或編譯）。

- **書架**：每個主題是一本書。目前有 🚚 交通工具（工地、蓋大樓、消防救援、農場、貨運卡車、海上、天空、太空）、🦁 動物（草原、叢林、農場動物、海洋、極地、森林、寵物），🦕 恐龍（恐龍山谷、遠古天空、遠古海洋；恐龍蛋巢、火山、化石博物館 預定中），🦷 我的身體 先預留（還沒做好的頁面和主題顯示「敬請期待」）
- **目錄**：一本書有好幾頁，做好的頁面可以點進去，還沒做的顯示「敬請期待」
- **翻頁**：按右上角的 ◀ ▶，或在畫面上左右滑，會像真的書一樣把一頁翻過去
- **焦點模式**：點車子時，其他東西變暗，被點的車子轉正、放大跑到畫面中間做動作，做完再回原位
- **場景**：車子前後錯開、有的斜斜地停在土堆上，旁邊印著英文小標籤；點車子會先唸英文名字、跳出英文＋中文名牌，然後像機關書一樣動起來。還沒點過的車子上有一顆會閃的紅點
- **加到主畫面（PWA）**：iPad 用 Safari「分享 → 加入主畫面」，開過一次以後沒有網路也能用

車子和背景是用本機的開源 AI（ComfyUI＋FLUX.1 schnell）以文字提示詞生成的扁平插畫。會動的零件用 SVG clipPath 從圖上裁出來單獨轉動，塔吊的鋼索、吊鉤和鋼樑則是用程式畫的。玩法參考機關書，但沒有照描、也沒有拿任何書的圖去給 AI 當參考。生成和去背的工具在 `tools/ai-art/`。

英文語音（車名和 Honk honk 之類的音效）是用開源的 Qwen3-TTS 預先生成的 mp3（`public/audio/en/`，清單在 `public/voices.js`），沒有音檔的句子會退回瀏覽器語音。做法見 `tools/voice/README.md`。

| Velociraptor 迅猛龍 | 一溜煙跑過去、轉身跑回來，再跳一下 |
| Parasaurolophus 副櫛龍 | 抬起頭「Honk honk!」叫，嘴巴冒出聲波 |

### 🦅 恐龍：遠古天空（Prehistoric Sky）

場景是海邊的懸崖。翼龍都用「側面、翅膀往上舉」的姿勢生圖：翅膀沿著肩膀那一條水平線裁出來（零件 `wing`），拍翅膀就是把 `wing` 的 `sy` 從 1 壓到負的（翅膀翻到下面），水平線上的點不會動，接縫看不出來。翅膀的裁切範圍要避開脖子和頭冠，可以用 Python 讀 WebP 的透明度確認邊界。會飛來飛去的用 `focus: false`，在原本的畫面裡飛。

| 動物 | 點了會怎樣 |
|---|---|
| Pteranodon 無齒翼龍 | 拍拍翅膀，在天空飛一個橫的 8 字再回來 |
| Quetzalcoatlus 風神翼龍 | 最大的翼龍，慢慢拍大翅膀往左滑翔，再飛回來 |
| Rhamphorhynchus 喙嘴翼龍 | 俯衝到海裡「Splash!」，叼起一條魚（SVG）飛回來 |
| Tapejara 古神翼龍 | 抬頭秀出大紅頭冠，拍翅膀上下飛 |
| Dimorphodon 雙型齒翼龍 | 站在沙灘上「Squawk!」大叫，點點頭再跳兩下 |
| Archaeopteryx 始祖鳥 | 站在懸崖頂上，拍拍翅膀飛一小圈再回來 |
| Microraptor 小盜龍 | 從大樹上滑翔到沙灘上空，再拍翅膀飛回樹上 |

### 🌊 恐龍：遠古海洋（Prehistoric Sea）

版面跟動物書的海洋一樣：上面是天空，海面在 y ≈ 375，下面是海水和沙地。蛇頸龍的脖子、滄龍的尾巴用 `joint()` 裁出來轉，轉軸上蓋一圈原圖遮住切口。AI 一直把菊石畫成蝸牛、三葉蟲畫成鼠婦，選了最接近的。魚龍用 `focus: false`，才是真的從海面跳出去。

| 動物 | 點了會怎樣 |
|---|---|
| Ichthyosaurus 魚龍 | 像海豚一樣跳出水面翻身，「Splash!」濺起水花 |
| Plesiosaurus 蛇頸龍 | 長脖子伸到海面換氣，擺一擺，再划鰭游一段 |
| Archelon 古巨龜 | 慢慢划水往前游，冒一串泡泡，再游回來 |
| Mosasaurus 滄龍 | 尾鰭甩一甩，往前衝「Chomp chomp!」咬兩口 |
| Ammonite 菊石 | 觸手揮一揮，「Whoosh!」往後噴水衝出去，再漂回來 |
| Dunkleosteus 鄧氏魚 | 往前衝「Chomp chomp!」咬兩口 |
| Trilobite 三葉蟲 | 在沙地上爬，縮成一團滾一圈，再爬回來 |

## 新增一頁

1. 在 `themes.js` 對應主題的 `pages` 加一筆（例如 `{ id: 'sea', icon: '🚢', en: 'Sea', zh: '海上' }`，交通工具這本已經預留好了）
2. 新增 `art/<頁面 id>.js`，照 `construction.js` 或 `rescue.js` 的寫法用 `SCENES['<頁面 id>'] = { ... }` 畫場景、寫每台車的動作
3. 在 `index.html` 加上 `<script src="art/<頁面 id>.js"></script>`，在 `sw.js` 的 `CORE` 加上檔名（包含 `art/img/<頁面 id>/` 的圖片），並把 `CACHE` 版本號 +1
4. 插畫照 `tools/ai-art/README.md` 的流程生成
