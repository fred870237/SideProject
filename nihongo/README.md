# 小小日語樂園 🦊

互動式日語學習網頁（純 HTML/CSS/JS，不需要安裝或編譯）。首頁上方可切換 **🧒 兒童模式** 與 **🧑 大人模式**，兩者共用同一個網址與進度。

## 大人模式（JLPT N5）

- **今日複習（間隔重複 SRS）**：N5 單字 692 個、N5 漢字 103 個。每張卡依「忘了／困難／記得／簡單」自動排下次複習日（簡化版 SM-2），每天新字數可設 5／10／20；有漢字的單字可打字回答讀音，支援鍵盤快捷鍵（空白鍵翻面、1～4 評分）
- **羅馬拼音輸入**：打 taberu 會即時轉成 たべる，也可直接用日文輸入法；比對時長音、ぢ/じ、づ/ず 視為相同
- **N5 單字**：依主題分類、可搜尋中文／假名／漢字／羅馬拼音，標示未學、學習中、熟練
- **N5 漢字**：音讀、訓讀、例字、筆順動畫與描字挑戰
- **N5 文法**：32 個句型（は／を／に／で／へ、て形、〜たい、〜てもいい…），每個有中文說明與 3 個例句；練習分「助詞・活用填空」與「句子重組」，也有 10 題綜合練習
- **例句聽力**：聽例句選出中文意思，可切換慢速
- **打字練習**：看中文打出日文讀音，10 題一回
- **拗音・特殊音**：拗音表、促音、長音、片假名外來語特殊音，附例字

- **深色模式**：設定裡可選「跟隨系統／淺色／深色」，兒童模式也適用

> N5 字表為非官方整理（JLPT 官方未公布字彙表）。資料在 `public/n5.js`，格式簡單、可自行增修。

## 兒童模式

- **冒險地圖**：29 個關卡，分成🌳平假名森林、🌊片假名海洋（打敗平假名大魔王後解鎖）、🏰單字城堡。每關先學再挑戰，答對 6/8 題過關，依成績得 1～3 星，第一次過關多送 5 顆星，過關後解鎖下一關
- **平假名 / 片假名**：清音、濁音・半濁音五十音表，點字即發音，可彈出大字卡、看對應假名、例字，播放**筆順動畫**（標示起筆編號），並用手指描字練習；「描字挑戰」會逐筆檢查位置、方向與順序，即時提示，同一畫錯 3 次自動示範，最後依錯誤次數給 1～3 星
- **單字卡**：動物、食物、顏色、數字、家人、打招呼，點卡片發音，可「全部唸一遍」
- **小測驗**：6 種題型（聽音找字、看字選讀音、聽日語找圖、看圖選日語），答對得星星
- **錯題複習**：答錯的字自動進「錯題本」，之後的測驗會優先多考；專屬複習模式答對 2 次就畢業。五十音表上會用橘框標出要加油的字
- **每日目標**：首頁顯示今天拿到幾顆星（預設 15 顆，可在「我的進度」改成 10/15/20/30）、這週達成紀錄與🔥連續天數
- **貼紙本**：用 10 顆星轉扭蛋抽動物／海洋／甜點貼紙（每張都有日語名字，點了會唸）；另有 7 張特別貼紙靠成就取得（第一次過關、打敗大魔王、全對、連續 3／7 天、達成目標 5 次、描字挑戰 3 星）
- **翻牌配對**：圖片 ↔ 日語記憶遊戲
- **我的進度**：星星、勳章、聽過的字、各測驗最佳成績（存在瀏覽器 localStorage）
- 可「加到主畫面」當 App 使用（PWA，支援離線）

發音使用瀏覽器內建的語音合成（Web Speech API）。建議 Chrome / Edge / Safari；若裝置沒有日語語音，首頁會提示。

## 檔案結構

```
nihongo/
├─ netlify.toml        # Netlify 設定（發佈 public 資料夾）
└─ public/
   ├─ index.html
   ├─ style.css
   ├─ app.js           # 共用工具與兒童模式頁面
   ├─ adult.js         # 大人模式：羅馬拼音轉換、SRS 複習、N5 單字／漢字頁
   ├─ data.js          # 五十音與兒童單字資料
   ├─ n5.js            # JLPT N5 單字與漢字資料
   ├─ grammar.js       # N5 文法句型與例句
   ├─ strokes.js       # 假名筆順資料（KanjiVG）
   ├─ strokes-extra.js # N5 漢字與小寫假名筆順資料（KanjiVG）
   ├─ sw.js            # 離線快取
   ├─ manifest.webmanifest
   └─ icon.svg
```

## 本機預覽

```bash
python -m http.server 8766 -d public
```

再開啟 http://localhost:8766

## 部署到 Netlify

**方法一：拖放（最快）**
到 https://app.netlify.com/drop ，把 `public` 資料夾拖進去即可。

**方法二：連結 GitHub（之後 push 就自動更新）**
1. 把 `nihongo` 資料夾推到一個 GitHub repo
2. Netlify → Add new site → Import an existing project → 選該 repo
3. Build command 留空，Publish directory 會自動讀取 `netlify.toml` 的 `public`

**方法三：Netlify CLI**

```bash
npx netlify-cli deploy --prod --dir public
```

## 新增單字

在 `public/data.js` 的 `VOCAB` 裡加一筆，例如：

```js
{ e: '🐸', jp: 'かえる', ro: 'kaeru', zh: '青蛙' },
```

測驗與翻牌遊戲會自動用到新單字。
