# 經典故事書 📚

給小朋友點擊翻頁看經典故事的網頁（純 HTML/CSS/JS，不需要安裝或編譯）。

- **書架**：依地區分類（台灣／中國／日本／英國／美國／歐洲），上方可切換分頁，「全部」會依地區分段顯示；讀完的書會貼上 ⭐
- **翻頁**：點畫面右邊／按 ▶ 下一頁；點左邊三分之一／按 ◀ 上一頁；手機可左右滑動；電腦可用 ← → 鍵
- **自動播放**：閱讀畫面上方的 ▶ 按下後，每一頁唸完會自動翻下一頁，一直播到故事結束（再按 ⏸ 暫停；在最後一頁按會從頭播）。自動播放不需要另外開 🔊
- **注音**：右上角 ㄅ 按鈕開關注音（預設開），注音直排在字的右邊，用台灣讀音（一、不標本調）
- **朗讀**：右上角 🔈 開啟後，每翻一頁就用瀏覽器內建語音（中文）唸出來；唸到的字會用黃色標示，唸過的字變橘色
  - Windows 的 Microsoft 語音、Edge 會回報唸到哪個詞，標示會準確同步
  - 不回報的語音（例如 Chrome 的 Google 語音、部分手機）改用估計的速度一個字一個字往前標，可能略快或略慢
- **小問答**：每本書讀完有 3 題選擇題（有注音、會唸題目，答對有音效並自動翻頁），之後是「和爸爸媽媽聊一聊」的 2 個討論題；3 題都一次答對，書架上會貼 🏅
- **睡前模式**：書架上的 🌙 按鈕，選讀幾本（1～3 本）。畫面變暗、唸得比較慢、不出小問答；讀完設定的本數會出現「晚安」畫面，要爸媽長按 3 秒才能解除（12 小時後自動關閉）
- **加到主畫面（PWA）**：iPad 用 Safari 的「分享 → 加入主畫面」，電腦用 Chrome／Edge 網址列的安裝按鈕，就能像 App 一樣全螢幕開啟；開過一次以後，所有書都會存起來，沒有網路也能讀
- **插畫**：30 本書都有用程式畫的 SVG 插畫（382 張），插畫鋪滿整頁，文字疊在上方的半透明框裡
- 平板／電腦橫放時圖文左右並排，手機直放時上圖下文

## 檔案結構

```
storybook/
├─ netlify.toml          # Netlify 設定（發佈 public 資料夾）
├─ tools/                # 只在自己電腦跑，不會部署
│  ├─ add-zhuyin.mjs     # 產生注音
│  └─ scenes/            # 畫插畫（見下方「插畫」）
│     ├─ lib.mjs         # 共用：背景、人物、動物、輸出
│     ├─ <地區>-common.mjs # 各地區共用的角色和背景（jp、tw、cn、uk、us、eu）
│     ├─ <id>.mjs        # 每本書一個
│     └─ link-images.mjs # 把畫好的插畫接到書的資料
└─ public/
   ├─ index.html
   ├─ style.css
   ├─ app.js
   ├─ sw.js              # 離線快取（service worker）
   ├─ manifest.webmanifest
   ├─ icons/             # 加到主畫面用的圖示
   └─ books/
      ├─ index.json      # 地區與書架清單
      ├─ <id>.json       # 每本書一個檔
      └─ <id>/           # 每本書的插畫（cover.svg、01.svg…）
```

## 新增一本書

1. 在 `public/books/` 新增 `<id>.json`（id 只能用英文、數字、`-`）：

   ```json
   {
     "id": "urashima",
     "title": "浦島太郎",
     "cover": "🐢",
     "color": "#cdeefd",
     "pages": [
       { "scene": "👦🎣🌊", "bg": "#dff3ff", "text": "很久很久以前……" },
       { "image": "books/urashima/02.webp", "text": "也可以用圖片代替 emoji。" }
     ],
     "quiz": [
       { "text": "浦島太郎救了誰？", "options": [
         { "icon": "🐢", "text": "小海龜" },
         { "icon": "🐟", "text": "小魚" },
         { "icon": "🦀", "text": "螃蟹" }
       ] }
     ],
     "talk": [
       { "text": "如果你是浦島太郎，你會打開玉手箱嗎？為什麼？" }
     ]
   }
   ```

   - `scene`：用 emoji 組成的畫面；`image`：插畫圖片路徑（有 `image` 時優先用圖）
   - `bg`：該頁背景色（可省略）
   - 插圖建議放在 `public/books/<id>/`，用 webp 或 svg、寬 1200px 左右；`coverImage` 可以讓封面也用插圖（`index.json` 那一行也要加，書架才會顯示）
   - `quiz`：小問答，**第一個選項是正確答案**（畫面上會自動打亂順序）；`icon` 可省略。建議每本 3 題
   - `talk`：讀完後的親子討論題，建議 2 題
   - `quiz`、`talk` 都可以省略，省略就不顯示

2. 在 `public/books/index.json` 的 `books` 陣列加一行：

   ```json
   { "id": "urashima", "region": "jp", "title": "浦島太郎", "cover": "🐢", "color": "#cdeefd" }
   ```

   `region` 對應 `index.json` 裡 `regions` 的 id：`tw` 台灣、`cn` 中國、`jp` 日本、`uk` 英國、`us` 美國、`eu` 歐洲（格林、安徒生、伊索等）。
   要新增地區，在 `regions` 加一行 `{ "id": "kr", "name": "韓國", "icon": "🏮" }` 即可（圖示建議用 emoji，不要用國旗——Windows 不會顯示國旗 emoji）。

3. 產生注音（需要 Node.js，第一次先在 `tools/` 執行 `npm install`）：

   ```bash
   node tools/add-zhuyin.mjs
   ```

   會幫還沒有注音、或文字改過的頁面（包括小問答和討論題）加上 `zhuyin` 欄位（空白分隔，一個漢字對一組注音，標點不算）。已經有的注音不會被覆蓋，所以可以直接在 JSON 裡手動修正讀音。

   - `--review`：列出破音字（長、得、地、了、著、還…）的讀音，方便檢查
   - `--force`：全部重新產生（會蓋掉手動修正）
   - 常見破音字規則寫在腳本的 `RULES`，遇到判斷錯的可以加規則
   - 文字改了但沒重新產生注音時，那一頁會自動不顯示注音，不會對錯位置

## 本機預覽

**最簡單**：在 Windows 雙擊 `開啟故事書.bat`，會自動開伺服器並打開瀏覽器；關掉黑色視窗就停止（需要電腦有 Python 或 Node.js）。

`fetch` 讀 JSON 需要透過伺服器，直接雙擊 `index.html` 會讀不到書：

手動啟動的話：

```bash
python -m http.server 8767 -d public
```

再打開 http://localhost:8767

離線快取是「網路優先」：有網路時永遠讀最新的檔案，改完程式或故事重新整理就看得到，不用另外清快取。

## 插畫

插畫都是用程式畫的 SVG，不是下載的圖片，所以沒有版權問題：

- `tools/scenes/lib.mjs`：共用的背景、表情、通用人物 `person()`（可換服裝、髮型、帽子、鬍子、姿勢、表情）、動物，和輸出工具
- `tools/scenes/<地區>-common.mjs`：各地區共用的角色和背景
- `tools/scenes/<id>.mjs`：每本書先定義主角，再組成每一頁的場景

修改某本書的插畫後重新產生（加 `--sheet` 會另外輸出預覽圖 `tools/scenes/_preview/<id>.png`，紅色虛線以上是文字區，需要 Microsoft Edge）：

```bash
node tools/scenes/kintaro.mjs --sheet
```

新增一本書的插畫：照現有的腳本寫一個 `<id>.mjs`（張數 = 頁數 + 封面，檔名 `cover`、`01`、`02`…），產生後執行下面的指令，把插畫接到書的 JSON 和書架：

```bash
node tools/scenes/link-images.mjs
```

也可以直接把畫好的圖（webp／svg）放進 `public/books/<id>/`，用同樣的檔名，再執行上面的指令。

有插畫的頁面會**滿版**顯示，故事文字疊在畫面上方，所以畫圖時要注意：

- **上方約 30% 留給文字**（800×600 的畫面中，y 小於 180 的範圍）：只放天空、雲、太陽這類被蓋到也沒關係的東西，角色和重要道具放下半部
- **SVG 插畫**：背景（天空、地面、海）要往 800×600 外多畫一圈（見腳本裡的 `BX`、`BW`、`BY`），根元素加 `preserveAspectRatio="xMidYMax meet"`。這樣不同比例的螢幕只會多露出背景，角色不會被裁掉；手機直放時上方會多出一片天空，文字就放在那裡
- **一般圖片（webp／png）**：會等比例放大鋪滿、靠下對齊，左右或上方可能被裁掉一些，重要的東西不要放在邊緣

## 部署到 Netlify

- **拖放**：登入 Netlify → Sites → 把 `public` 資料夾拖進去即可
- **連 GitHub**：把這個資料夾推上 GitHub，在 Netlify 選 Import from Git，`netlify.toml` 已設定好發佈 `public`，Build command 留空
