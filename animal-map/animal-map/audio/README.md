# 音檔放置說明

有兩種方式加入發音，擇一即可：

1. **直接在 iPad 上錄**（最簡單）：按住右上角 ⚙️ 2 秒進入家長模式，點動物，按「🎙️ 錄音」。錄音存在那台 iPad 上。
2. **放 mp3 檔到這個資料夾**：檔名用動物的 id，例如 `audio/tw/lion.mp3`。放好後重新上傳網站，所有 iPad 都會使用。

播放優先順序：家長錄音 → 這裡的 mp3 → 系統語音（只有英文、中文有系統語音）。
